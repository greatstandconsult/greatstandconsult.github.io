# Great Stand Educational Consult Website

A responsive, premium static website for Great Stand Educational Consult.

## Included
- Responsive homepage
- Existing Great Stand logo
- Founder profiles for A.O. Joshua and Joseph Olawale
- JAMB/UTME, WAEC, Post-UTME and consultancy services
- Educational updates section
- Contact section with phone, email and direct WhatsApp links
- Mobile navigation
- Subtle scroll animations

## Files
- index.html — main website
- styles.css — visual design
- script.js — menu and animation behaviour
- assets/ — logo and founder photos
